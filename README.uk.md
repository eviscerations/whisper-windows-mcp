# whisper-windows-mcp

[![CI](https://github.com/eviscerations/whisper-windows-mcp/actions/workflows/ci.yml/badge.svg)](https://github.com/eviscerations/whisper-windows-mcp/actions/workflows/ci.yml)

[![whisper-windows-mcp MCP server](https://glama.ai/mcp/servers/eviscerations/whisper-windows-mcp/badges/card.svg)](https://glama.ai/mcp/servers/eviscerations/whisper-windows-mcp)

Нативний MCP-сервер (Model Context Protocol) для Windows. Використовує [whisper.cpp](https://github.com/ggml-org/whisper.cpp) для транскрибування аудіо та відеофайлів локально в Claude Desktop — з апаратним прискоренням GPU, підтримкою багатьох мов і пакетним опрацюванням. Уся транскрипція виконується локально — жодні аудіо-, відеофайли чи шляхи до файлів не передаються назовні.

> **Чому існує цей пакет?**
> Популярний пакет `whisper-mcp` створено для macOS і розрахований на Unix-середовище. На Windows він не працює. Цей пакет написано спеціально для користувачів Windows, які хочуть локальне AI-транскрибування, інтегроване з Claude Desktop.

---

## Що ви можете робити

Після встановлення можна говорити прямо в Claude Desktop:

- *"Транскрибуй C:\Users\Me\Downloads\meeting.mp3"*
- *"Транскрибуй всі записи в цій теці й збережи кожен як текстовий файл"*
- *"Створи українські та англійські субтитри для цього відео"*
- *"Почни пакетне транскрибування всіх файлів у цій теці"*
- *"Скільки часу займе транскрибування цих файлів?"*
- *"Перевір, чи працює прискорення GPU"*
- *"Транскрибуй цей файл у режимі конфіденційності"*

## Крок 1 — Встановлення бінарників whisper.cpp

### Варіант А — Готовий Vulkan-реліз (рекомендовано)

Завантажте `whisper-vulkan-win-x64.zip` зі [сторінки релізів](https://github.com/eviscerations/whisper-windows-mcp/releases/tag/v1.4.0).

Це спеціальна збірка з увімкненим **Vulkan GPU-прискоренням**. Працює з GPU від AMD, NVIDIA та Intel — без потреби в окремих SDK від виробника.

Розпакуйте в `C:\whisper\Release\`. Ви маєте отримати такі файли:

```
C:\whisper\Release\whisper-cli.exe
C:\whisper\Release\ggml-vulkan.dll
C:\whisper\Release\ggml.dll
C:\whisper\Release\ggml-base.dll
C:\whisper\Release\ggml-cpu.dll
C:\whisper\Release\whisper.dll
```

Прискорення GPU вмикається автоматично — жодних додаткових налаштувань не потрібно.

### Варіант Б — Збірка з вихідного коду

Потрібно: Git, CMake, Visual Studio Build Tools 2022+ з компонентом "Desktop development with C++", Vulkan SDK з [lunarg.com](https://vulkan.lunarg.com/sdk/home#windows).

```
git clone https://github.com/ggml-org/whisper.cpp
cd whisper.cpp
cmake -B build -DGGML_VULKAN=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --target whisper-cli
```

Скопіюйте бінарники з `build\bin\Release\` до `C:\whisper\Release\`.

> **Примітка:** Офіційні Windows-релізи whisper.cpp на GitHub не містять Vulkan-збірки. Використовуйте готовий реліз вище або компілюйте з вихідного коду з прапором `-DGGML_VULKAN=ON`.

## Крок 2 — Завантаження моделі Whisper

| Модель | Розмір | Швидкість | Точність | Найкраще для |
|---|---|---|---|---|
| `ggml-tiny.en.bin` | 75 МБ | Дуже швидко | Базова | Швидкі тести |
| `ggml-base.en.bin` | 142 МБ | Швидко | Добра | Щоденна англійська |
| `ggml-small.en.bin` | 466 МБ | Помірно | Краща | Важливі записи |
| `ggml-medium.en.bin` | 1.5 ГБ | Швидко на GPU | Дуже добра | Найвища якість англійської |
| `ggml-large-v3-turbo.bin` | 1.6 ГБ | Швидко на GPU | Відмінна | **Рекомендовано для пакетної обробки на GPU — ~у 6 разів швидше за large-v3 з мінімальною втратою точності** |
| `ggml-large-v3.bin` | 2.9 ГБ | Швидко на GPU | Відмінна | Багатомовний, максимальна точність |
| `ggml-medium.en-q5_0.bin` | 514 МБ | Швидко | Дуже добра | **Найкращий вибір для CPU-only англійської — висока точність при малому обсязі пам'яті** |
| `ggml-large-v3-turbo-q5_0.bin` | 547 МБ | Швидко | Відмінна | **Найкращий вибір для CPU-only багатомовного** |
| `ggml-large-v3-q5_0.bin` | 1.1 ГБ | Помірно на CPU | Відмінна | Багатомовний, сприятливий для CPU |

Використовуйте `download_model` у Claude Desktop для встановлення безпосередньо. Для **лише англійської**: `large-v3-turbo` (GPU) або `medium.en-q5_0` (CPU) — найкращий вибір. Для **багатомовного**: `large-v3-turbo` або `large-v3-turbo-q5_0` (CPU). Моделі лише для англійської (`*.en.bin`) виводять `[FOREIGN]` для не-англійського аудіо і не можуть використовуватися для інших мов.

## Крок 5 — Налаштування Claude Desktop

Відкрийте Claude Desktop → Налаштування → Розробник → Редагувати конфігурацію.

Додайте запис `whisper`:

```json
{
  "mcpServers": {
    "whisper": {
      "command": "npx",
      "args": ["-y", "whisper-windows-mcp"],
      "env": {
        "WHISPER_CLI_PATH": "C:\\whisper\\Release\\whisper-cli.exe",
        "WHISPER_MODEL": "C:\\whisper\\models\\ggml-medium.en.bin"
      }
    }
  }
}
```

Розташування файлу конфігурації: `C:\Users\ВашеІм'я\AppData\Roaming\Claude\claude_desktop_config.json`

> Використовуйте **подвійний зворотній слеш** у всіх шляхах.

Збережіть і **повністю перезапустіть** Claude Desktop. Ви маєте побачити **whisper** у списку зі зеленим значком "запущено" в Налаштуваннях → Розробник.

## Доступні інструменти

### `transcribe_audio`
Транскрибує один файл. Підтримує блокувальний (типово) або фоновий режим для довгих файлів.

| Параметр | Опис |
|---|---|
| `file_path` | Абсолютний шлях до файлу (обов'язково) |
| `language` | Код мови (`uk`, `en`, `ja` тощо) або `auto` для автовизначення. Типово: `en` |
| `output_format` | `timestamps` (типово), `text`, `json`, `srt`, `vtt`, `lrc` або `csv` |
| `save_to_file` | Зберегти транскрипцію як .txt поруч із вихідним файлом |
| `background` | Запустити як окреме завдання — одразу повертає ID завдання. Використовуйте `check_progress` для стеження. Рекомендовано для файлів понад 10 хвилин. |
| `privacy_mode` | Перевизначити режим конфіденційності для цього виклику. `true` = лише метадані, жоден текст транскрипції не передається. `false` = повертати текст навіть якщо `WHISPER_PRIVACY_MODE=true` глобально. Пропустіть для використання глобального налаштування. |
| `threads` | Перевизначити кількість потоків CPU |
| `temperature` | Температура вибірки 0.0–1.0. Типово 0.0 (детерміновано). |
| `prompt` | Рядок попереднього контексту — підвищує точність для галузевої лексики або імен доповідачів. Приклад: `"Імена: Keemstar, DramaAlert."` |
| `condition_on_prev_text` | Повторно увімкнути контекстне обумовлення між сегментами. Типово false. |
| `beam_size` | Ширина пошуку за промінем. Вище = точніше, повільніше. Типово 5. |
| `best_of` | Кількість оцінюваних послідовностей-кандидатів. Типово 5. |
| `gpu_device` | Індекс пристрою GPU для багатогрупових систем. Типово 0. |
| `processors` | Кількість паралельних процесорів. Типово 1. |
| `word_timestamps` | Один рядок на слово з мітками часу. Корисно для вирівнювання кліпів. |
| `max_segment_length` | Максимальна довжина сегмента в символах. |
| `diarize` | Стерео-розрізнення доповідачів — потребує стерео аудіо з доповідачами на окремих каналах. |
| `vad_model` | Шлях до .bin-файлу моделі Silero VAD. Видаляє тишу перед транскрипцією — зменшує галюцинації у шумних файлах. |
| `offset_t` | Зміщення початку в мілісекундах. |
| `duration` | Тривалість опрацювання в мілісекундах від зміщення. |

**Формати виводу:**
- `timestamps` — сегменти з мітками часу, наприклад `[00:00:01.230 --> 00:00:04.560]  Привіт` (типово)
- `text` — простий текст без часових кодів
- `json` — структурований JSON (лише блокувальний режим)
- `srt` — файл субтитрів SubRip, збережений поруч із джерелом
- `vtt` — файл субтитрів WebVTT, збережений поруч із джерелом
- `lrc` — формат LRC текстів/караоке, збережений поруч із джерелом
- `csv` — CSV з мітками часу, збережений поруч із джерелом

### `check_progress`
Стежить за фоновим завданням транскрипції, запущеним через `transcribe_audio` (background=true).

Повертає минулий час, останню опрацьовану мітку часу і повну транскрипцію після завершення.

| Параметр | Опис |
|---|---|
| `job_id` | ID завдання, повернений `transcribe_audio` |
| `privacy_mode` | Перевизначити режим конфіденційності для цієї перевірки. `true` = лише метадані, незалежно від способу запуску завдання. |

---

### `start_batch`
Автоматично і послідовно транскрибує всі ще не транскрибовані файли в теці. Сортує за тривалістю (від найкоротших), опрацьовує по одному як фонові завдання, перевіряє кожен результат. Пакет самостійно просувається після завершення кожного файлу — опитування не потрібно.

| Параметр | Опис |
|---|---|
| `folder_path` | Шлях до теки (обов'язково) |
| `language` | Код мови. Типово: `en` |
| `threads` | Перевизначити кількість потоків CPU |
| `output_format` | `timestamps` (типово) або `text` |
| `privacy_mode` | Перевизначити режим конфіденційності. Перед початком пакету потрібне одне підтвердження; далі всі файли опрацьовуються без нагляду. Текст транскрипції не повертається. |

---

### `check_batch_progress`
Стежить за запущеним пакетом. Автоматично переходить до наступного файлу після завершення поточного. Повертає загальний прогрес, поточний файл з міткою часу і файли з помилками.

| Параметр | Опис |
|---|---|
| `batch_id` | ID пакету, повернений `start_batch` |

---

### `transcribe_batch` (інтерактивний)
Опрацьовує файли по одному з попереднім переглядом і підтвердженням перед кожним. Корисно, коли хочеться переглядати результати в процесі.

| Параметр | Опис |
|---|---|
| `folder_path` | Шлях до теки (обов'язково) |
| `file_index` | Який файл опрацювати (нумерація з 1). Пропустіть, щоб спочатку показати список файлів. |
| `language` | Код мови. Типово: `en` |
| `recursive` | Включити підтеки |
| `output_format` | `timestamps` (типово) або `text` |
| `privacy_mode` | Перевизначити режим конфіденційності. Підтвердження потрібне перед кожним файлом; повертаються лише метадані. |

---

### `generate_subtitles`
Створює файли субтитрів. Підтримує автовизначення мови та вивід перекладу англійською. Виводить SRT (найширша сумісність) або WebVTT (веб і HTML5 відео).

| Параметр | Опис |
|---|---|
| `file_path` | Шлях до файлу (обов'язково) |
| `language` | Код мови або `auto` для автовизначення. Типово: `en` |
| `output_format` | `srt` (типово) або `vtt` |
| `translate_to_english` | Також створити файл субтитрів з перекладом англійською. Застосовується лише якщо джерело — не англійська. |
| `background` | Запустити як фонове завдання. Повертає ID завдання для `check_progress`. |
| `threads` | Перевизначити кількість потоків CPU |

Коли запитуються обидва варіанти, поруч із джерелом зберігаються два файли:
- `назвафайлу.uk.srt` — рідна мова
- `назвафайлу.en.srt` — переклад англійською

> Вбудований переклад Whisper перекладає **лише на англійську**. Для інших цільових мов перекладайте вміст .srt-файлу окремо.

### `analyze_media`
Аналізує файли перед транскрипцією. Повертає тривалість, розмір, кодек і орієнтовний час транскрипції на CPU та GPU. Для теки показує всі файли у таблиці з можливістю сортування й статусом транскрипції.

| Параметр | Опис |
|---|---|
| `path` | Шлях до окремого файлу або теки (обов'язково) |
| `sort_by` | Для теки: `duration` (типово), `name` або `size` |

---

### `check_config`
Перевіряє, чи доступні whisper-cli.exe, файл моделі та FFmpeg. Запускайте це першим, якщо щось не працює.

---

### `list_models`
Перелічує всі встановлені файли моделей Whisper у вашій теці моделей. Показує ім'я файлу, розмір, чи активна модель, статус квантизації та рекомендовані випадки використання. Без мережевих запитів — лише читання локальної файлової системи.

---

### `download_model`
Завантажує модель Whisper безпосередньо з Hugging Face до вашої теки моделей. Завантажує лише з довірених просторів імен Hugging Face. Після завантаження активуйте через `switch_model`.

| Параметр | Опис |
|---|---|
| `model_name` | Назва моделі для завантаження, наприклад `large-v3-turbo`, `large-v3-turbo-q5_0`, `medium.en-q5_0` |

---

### `switch_model`
Перемикає активну модель Whisper для поточного сеансу без перезапуску Claude Desktop. Зміна діє лише в межах сеансу — після перезапуску не зберігається. Щоб зробити постійним, оновіть `WHISPER_MODEL` у конфігурації.

| Параметр | Опис |
|---|---|
| `model_name` | Ім'я файлу моделі (наприклад `ggml-large-v3-turbo.bin`) або повний шлях. Має бути `.bin`-файлом у налаштованій теці моделей. |

---

### `check_system`
Визначає апаратне забезпечення GPU і перевіряє доступність прискорення Vulkan. Повідомляє назву GPU, обсяг VRAM, наявність `ggml-vulkan.dll` і рекомендує найкращий розмір моделі для вашого обладнання.

## Прискорення GPU

Готовий Vulkan-реліз автоматично вмикає прискорення GPU. Протестовано на AMD Radeon RX Vega 56 (GCN 5-го покоління). Будь-який GPU з підтримкою Vulkan 1.0+ має працювати, включно з NVIDIA та Intel Arc.

**Порівняння продуктивності (модель large-v3, аудіофайл ~14 хвилин):**

| Обладнання | Час |
|---|---|
| Лише CPU (Ryzen 7 2700x, 8 потоків) | ~22 хвилини (орієнтовно) |
| GPU (Vega 56 через Vulkan) | ~3хв 22с |

Навантаження GPU під час транскрипції зазвичай становить 15–20% і повертається до простою між файлами.

Підтримує Windows 10 і Windows 11.

## Багатомовна підтримка

Whisper може автоматично визначати мову мовлення і транскрибувати нею. Вбудована модель перекладу перекладає **лише на англійську**.

Для найкращої точності у багатомовному режимі використовуйте модель `large-v3`. Моделі лише для англійської (`*.en.bin`) не можуть визначати або транскрибувати інші мови.

**Приклад — іноземне відео із субтитрами:**
1. Попросіть Claude створити субтитри з `language=auto` і `translate_to_english=true`
2. Whisper визначає мову і створює SRT або VTT рідною мовою
3. Другий прохід створює переклад англійською
4. Завантажте SRT у VLC через Субтитри → Додати файл субтитрів, або використовуйте VTT у будь-якому веб-плеєрі

## Конфіденційність і відповідність

whisper-windows-mcp містить вбудовану архітектуру конфіденційності для чутливого і регульованого контенту.

**Аудіо і відео ніколи не покидають ваш комп'ютер.** Ця гарантія є безумовною.

**Текст транскрипції** — інша справа: коли він повертається у відповіді інструменту, він опрацьовується API Claude. Для більшості користувачів це очікувана поведінка. Для регульованого контенту (медичного, юридичного, фінансового, корпоративного) режим конфіденційності запобігає цьому.

**Режим конфіденційності** обмежує всі відповіді інструментів лише метаданими (ім'я файлу, кількість слів, шлях збереження). Жоден текст транскрипції не передається API Claude за жодних обставин. Увімкніть для окремого виклику через `privacy_mode=true` у будь-якому інструменті транскрипції або глобально через `WHISPER_PRIVACY_MODE=true` у конфігурації.

**Ворота згоди** — при першому використанні за сеанс у стандартному режимі перед поверненням будь-якого тексту транскрипції відображається повне розкриття конфіденційності. Ви маєте явно підтвердити перед продовженням. Встановіть `WHISPER_CONSENT_ACKNOWLEDGED=true` у конфігурації, щоб пропустити це для нечутливого контенту.

Дивіться [PRIVACY.md](PRIVACY.md) для повного керівництва з відповідності (HIPAA, GDPR, адвокатська таємниця, FERPA, SOX, PCI-DSS).

## Розроблено для користувачів безкоштовного плану

Цей інструмент створено, щоб мінімізувати взаємодію з Claude API. Увесь робочий процес транскрипції — сканування, аналіз, черга, виконання, перевірка — розроблено так, щоб вимагати якомога менше взаємодій з Claude. Важка робота виконується локально на вашому комп'ютері.

## Додаткові змінні середовища

| Змінна | Опис |
|---|---|
| `WHISPER_CLI_PATH` | Шлях до whisper-cli.exe (обов'язково) |
| `WHISPER_MODEL` | Шлях до файлу моделі .bin (обов'язково) |
| `WHISPER_THREADS` | Перевизначити кількість потоків CPU |
| `WHISPER_GPU_DEVICE` | Індекс пристрою Vulkan, до якого прив'язати транскрипцію, для систем із кількома GPU (індекс перелічення Vulkan — перевірте журнал запуску whisper-cli; не порядок GPU у Windows). Можна перевизначити для окремого виклику через `gpu_device`. Дивіться [TROUBLESHOOTING.md](TROUBLESHOOTING.md). |
| `WHISPER_FOREGROUND_MAX_SEC` | Межа транскрипції на передньому плані в секундах (типово 210). Файли, виконання яких оцінюється як довше, спрямовуються у фоновий режим замість ризику ~4-хвилинного тайм-ауту інструмента Claude Desktop. |
| `FFMPEG_PATH` | Шлях до ffmpeg, якщо його немає в системному PATH |
| `WHISPER_PRIVACY_MODE` | При значенні `true` всі відповіді інструментів повертають лише метадані — жоден текст транскрипції не передається Claude. Для регульованого або конфіденційного контенту. Може бути перевизначено для окремого виклику через параметр `privacy_mode`. Дивіться [PRIVACY.md](PRIVACY.md). |
| `WHISPER_CONSENT_ACKNOWLEDGED` | При значенні `true` пропускає одноразове розкриття згоди сеансу перед поверненням тексту транскрипції. Встановіть після ознайомлення з межами конфіденційності, коли нагадування більше не потрібне. Не має ефекту, коли режим конфіденційності активний. |

## Безпека

**Перевірка бінарника.** Щоб перевірити цілісність бінарника whisper-cli.exe у готовому релізі, перевірте його хеш SHA256 у PowerShell:

```powershell
Get-FileHash "C:\whisper\Release\whisper-cli.exe" -Algorithm SHA256
```

Очікуваний хеш для релізного бінарника задокументовано на [сторінці релізів](https://github.com/eviscerations/whisper-windows-mcp/releases/tag/v1.4.0).

**Перевірка вхідних даних.** Усі шляхи до файлів перевіряються перед використанням — UNC-шляхи (`\\server\share`) і послідовності обходу теки (`..`) відхиляються. Файли понад 10 ГБ відхиляються для запобігання вичерпанню ресурсів.

**Усвідомлення ін'єкції транскрипції.** Аудіофайли можуть містити вимовлений контент, який після транскрипції нагадує інструкції. Вбудований захист Claude впорається з цим, але варто знати, що сам MCP-сервер обробляє вміст транскрипції як дані — ніколи як інструкції.

**Завантаження моделей обмежено.** Інструмент `download_model` завантажує лише з двох довірених просторів імен Hugging Face (`ggerganov/whisper.cpp` і `ggml-org`). Довільні URL-адреси відхиляються. Переспрямування перевіряються за списком дозволених перед виконанням.

**Перемикання моделей у пісочниці.** `switch_model` приймає лише `.bin`-файли з налаштованої теки моделей. Шляхи за межами цієї теки відхиляються.

Дивіться [SECURITY.md](SECURITY.md) для повної політики безпеки.

## Усунення несправностей

Детальні рішення — у [TROUBLESHOOTING.md](TROUBLESHOOTING.md). Якщо ви працюєте з регульованим контентом, дивіться також [PRIVACY.md](PRIVACY.md).

Швидкий контрольний список:
- Шляхи в конфігурації використовують **подвійний зворотній слеш** (`C:\\whisper\\...`)
- `whisper-cli.exe` існує за налаштованим шляхом
- Файл моделі `.bin` існує за налаштованим шляхом
- FFmpeg встановлено і доступно в PATH (`ffmpeg -version` працює)
- Claude Desktop **повністю перезапущено** після редагування конфігурації
- Whisper відображається як **запущено** (зелений значок) у Налаштуваннях → Розробник
