# Архітектура конфіденційності — whisper-windows-mcp

Цей документ описує, які дані залишаються на вашому комп'ютері, які дані його покидають і як налаштувати інструмент для регульованого або чутливого контенту.

---

## Основна гарантія

whisper-windows-mcp побудовано на архітектурі з пріоритетом локальності. **Аудіо- та відеофайли ніколи не покидають ваш комп'ютер.** Транскрипція виконується повністю на вашому апаратному забезпеченні за допомогою whisper.cpp — жодна хмарна служба, інтернет-з'єднання чи виклик API не задіяні в самій транскрипції.

Ця гарантія є безумовною для медіафайлів.

---

## Дані, що завжди залишаються локально

| Дані | Покидають комп'ютер? |
|---|---|
| Аудіофайли | ❌ Ніколи |
| Відеофайли | ❌ Ніколи |
| Файли моделей Whisper | ❌ Ніколи |
| Тимчасові WAV-файли конвертування | ❌ Ніколи (видаляються після транскрипції) |
| Файли стану пакетів і завдань | ❌ Ніколи |
| Файли транскрипцій `.txt` / `.srt` / `.vtt` на диску | ❌ Ніколи |

---

## Дані, що можуть покидати комп'ютер (стандартний режим)

Коли відповідь інструменту містить текст транскрипції, цей текст повертається до Claude Desktop і опрацьовується API Anthropic. Це стандартна поведінка MCP — текст передається з локального MCP-сервера до моделі Claude через мережу.

| Дані | Покидають комп'ютер? |
|---|---|
| Текст транскрипції, вбудований у відповіді інструментів | ✅ Так, у стандартному режимі |
| Текст транскрипції, завантажений напряму до Claude як файл | ✅ Так (поза MCP — жоден засіб контролю конфіденційності не застосовується) |

Цей розрив існує між гарантією інструменту "дані не покидають ваш комп'ютер" і фактичною поведінкою, коли ви просите Claude прочитати, узагальнити або проаналізувати транскрипцію. Більшості користувачів — тих, хто транскрибує публічний контент, як-от відео з YouTube, подкасти чи записи стрімів — це розрізнення не впливає.

Для користувачів, що працюють з приватними, конфіденційними або регульованими записами, це розрізнення важливе.

---

## Режим конфіденційності

`WHISPER_PRIVACY_MODE` обмежує всі відповіді інструментів лише метаданими. Коли активний:

- Відповіді інструментів повертають лише: ім'я файлу, кількість слів, шлях збереження, статус завершення
- Жоден текст транскрипції не включається до жодної відповіді інструменту
- Claude не може читати, аналізувати або передавати вміст транскрипції в жодній формі
- Транскрипції існують лише як локальні файли на диску

Режим конфіденційності розроблено для юридичних, медичних, фінансових і корпоративних розгортань, де вміст транскрипції за жодних обставин не має покидати локальне середовище.

### Глобальне увімкнення (змінна середовища)

Встановіть у `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "whisper": {
      "command": "npx",
      "args": ["-y", "whisper-windows-mcp"],
      "env": {
        "WHISPER_CLI_PATH": "C:\\whisper\\Release\\whisper-cli.exe",
        "WHISPER_MODEL": "C:\\whisper\\models\\ggml-large-v3.bin",
        "WHISPER_PRIVACY_MODE": "true"
      }
    }
  }
}
```

Для вступу в дію потрібен перезапуск Claude Desktop.

### Увімкнення для окремого виклику (без перезапуску)

Передайте `privacy_mode=true` безпосередньо будь-якому інструменту транскрипції:

- *"Транскрибуй цей файл у режимі конфіденційності"*
- *"Почни пакет у цій теці, privacy_mode=true"*
- *"Перевір прогрес завдання job_123, privacy_mode=true"*

Параметр для окремого виклику перевизначає глобальну змінну середовища в обох напрямках. Передайте `privacy_mode=false`, щоб вимкнути для одного виклику, навіть якщо `WHISPER_PRIVACY_MODE=true` глобально.

### Поведінка воріт режиму конфіденційності

Коли режим конфіденційності активний, підтвердження розкриття відображається **перед кожною операцією**. Це навмисно — відповідність нормативним вимогам потребує поінформованої згоди перед кожною подією опрацювання, а не лише один раз за сеанс.

Текст розкриття щоразу однаковий навмисно. Повторення — це і є суть: якщо ви працюєте з чутливим контентом, ви маєте явно підтверджувати кожну операцію.

Підтвердження прив'язане до **конкретної операції** — інструмента разом із його точними аргументами. Підтвердження однієї транскрипції не може задовольнити бар'єр іншої операції, а зміна будь-якого параметра вважається новою операцією, яка потребує власного підтвердження.

Для `start_batch` з режимом конфіденційності: перед початком пакету потрібне одне підтвердження. Далі всі файли опрацьовуються без нагляду. Текст транскрипції не повертається жодного разу — лише метадані прогресу пакету.

## Ворота згоди (стандартний режим)

Коли режим конфіденційності не активний, одноразове розкриття для сеансу відображається перед першим поверненням тексту транскрипції до API Claude за цей сеанс.

Розкриття охоплює:
- Що текст транскрипції буде передано до API Anthropic
- Нормативні рамки, які можуть застосовуватися до вашого контенту
- Як увімкнути режим конфіденційності за потреби
- Як назавжди пропустити ворота для нечутливого контенту

Після підтвердження ворота не спрацьовують протягом решти сеансу. Перезапуск Claude Desktop скидає сеанс, і ворота спрацюють знову при наступному виклику, що повертає транскрипцію.

**Для фонових завдань:** ворота згоди спрацьовують при завершенні `check_progress`, а не при виклику `transcribe_audio`. На момент виклику текст транскрипції ще не існує — нема чого блокувати. Ворота спрацьовують у момент, коли текст транскрипції вперше повертається до API.

### Постійне пропускання воріт

Якщо ви регулярно транскрибуєте нечутливий контент і вам більше не потрібне нагадування, встановіть у конфігурації:

```json
"WHISPER_CONSENT_ACKNOWLEDGED": "true"
```

Це не має ефекту, коли режим конфіденційності активний. Режим конфіденційності використовує власні ворота для кожної операції, які завжди спрацьовують незалежно від цього налаштування.

---

## Зведення потоків даних

| Режим | Аудіо | Текст транскрипції | Потрібне підтвердження |
|---|---|---|---|
| Стандартний | Лише локально | Надсилається до API Anthropic | Один раз за сеанс (ворота згоди) |
| Режим конфіденційності (змінна середовища) | Лише локально | Ніколи не передається | Перед кожною операцією |
| Режим конфіденційності (окремий виклик) | Лише локально | Не для цього виклику | Перед цією операцією |
| `WHISPER_CONSENT_ACKNOWLEDGED=true` | Лише локально | Надсилається до API Anthropic | Ніколи (пропущено) |

---

## Завантаження файлів транскрипцій напряму до Claude

Коли ви завантажуєте `.txt`-файл транскрипції напряму до Claude як вкладення файлу — повністю поза інструментом MCP — MCP-сервер не має видимості і не може застосувати жодні засоби контролю конфіденційності.

Завантаження транскрипції напряму до Claude рівнозначне надсиланню аудіовмісту до Anthropic. Режим конфіденційності та всі засоби захисту на рівні MCP повністю обходяться прямим завантаженням файлів.

Користувачі, що працюють з регульованим контентом, не повинні завантажувати транскрипції напряму до Claude. Єдиний безпечний шлях аналізу регульованого контенту — локальні інструменти опрацювання, що не передають контент назовні.

## Настанови для регульованих галузей

Нижченаведене є лише загальною інформацією. Автори цього інструменту не є юристами. Користувачі несуть повну відповідальність за дотримання застосовних законів і нормативних актів. За наявності сумнівів проконсультуйтеся з кваліфікованим юристом перед транскрибуванням регульованого контенту.

### HIPAA (США — охорона здоров'я)
Медичним закладам, страховикам та їхнім діловим партнерам заборонено передавати захищену медичну інформацію (PHI) неавторизованим третім сторонам без угоди про ділове партнерство (BAA). Anthropic не надає HIPAA BAA для використання споживчого API Claude.

**Відповідні випадки використання:** Консультації з пацієнтами, клінічні нотатки, сеанси терапії, дзвінки щодо страхових претензій, адміністративні записи лікарень.

**Рекомендація:** Увімкніть `WHISPER_PRIVACY_MODE=true` перед транскрибуванням будь-якого аудіо пацієнтів. Не вимикайте в середині сеансу.

### GDPR (ЄС/ЄЕЗ)
Персональні дані резидентів ЄС не можуть передаватися стороннім обробникам без явної згоди та правової підстави для опрацювання. Текст транскрипції, що містить імена, місцезнаходження або будь-яку ідентифікаційну інформацію, є персональними даними відповідно до GDPR.

**Відповідні випадки використання:** Інтерв'ю, наради, записи кол-центрів, судові провадження за участю резидентів ЄС.

**Рекомендація:** Увімкніть режим конфіденційності для будь-якого запису, що може містити персональні дані резидентів ЄС/ЄЕЗ.

### Адвокатська таємниця (США, Велика Британія, Австралія та більшість юрисдикцій загального права)
Спілкування між адвокатами та клієнтами охороняється законом. Розголошення неавторизованим третім сторонам може позбавити цього захисту. Не існує усталеної судової практики, яка захищала б адвокатську таємницю при опрацюванні комерційними AI API.

**Відповідні випадки використання:** Судові свідчення, консультації з клієнтами, внутрішні стратегічні записи, інтерв'ю зі свідками.

**Рекомендація:** Адвокати, що транскрибують привілейоване спілкування, мають увімкнути режим конфіденційності. Не вимикайте для аналізу — використовуйте локальні текстові редактори або інструменти опрацювання для привілейованого контенту.

### FERPA (США — освіта)
Освітні записи учнів захищені. Школи та університети не можуть розкривати ідентифіковану інформацію про учнів третім сторонам без згоди.

**Відповідні випадки використання:** Записані лекції, консультаційні сесії зі студентами, академічні слухання, зустрічі з IEP.

### SOX (США — публічні компанії)
Фінансові комунікації публічних компаній підпадають під вимоги щодо зберігання записів і конфіденційності. Суттєва непублічна інформація (MNPI) не може вибірково розкриватися.

**Відповідні випадки використання:** Записи дзвінків з результатами діяльності, протоколи засідань ради директорів, комунікації з інвесторами, обговорення внутрішньої фінансової стратегії.

### PCI-DSS
Дані платіжних карток не можна зберігати або передавати в незахищеному середовищі. Голосові записи номерів карток під час транзакцій підпадають під цю вимогу.

**Відповідні випадки використання:** Записи кол-центрів, дзвінки служби підтримки клієнтів з опрацюванням платежів.

### Захист комерційної таємниці / NDA
Конфіденційна ділова інформація, фірмові формули, деталі про не анонсовані продукти та кадрова інформація можуть захищатися договором або законом.

**Відповідні випадки використання:** Наради щодо корпоративної стратегії, обговорення R&D, дзвінки з перевірки належності під час M&A, кадрові провадження.
